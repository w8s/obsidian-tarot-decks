# Obsidian Tarot Decks

**Public domain divination decks for the [Obsidian Tarot Practice](https://github.com/w8s/obsidian-tarot-practice) plugin.**

This repository contains ready-to-use divination decks in JSON format that work with Obsidian Tarot Practice v1.7.0+. All decks are **public domain** and freely usable.

## 📦 Available Decks

### 🔮 Elder Futhark Runes (24 runes)
Norse divination system from 2nd-8th century CE. Each rune carries meaning related to prosperity, protection, journey, and spiritual growth.

**[Download](https://github.com/w8s/obsidian-tarot-decks/releases/latest/download/elder-futhark.zip)** | [View JSON](decks/elder-futhark/deck.json)

### 🃏 Petit Lenormand (36 cards)
French cartomancy system from early 1800s. Each card represents everyday objects, people, and situations for practical divination.

**[Download](https://github.com/w8s/obsidian-tarot-decks/releases/latest/download/lenormand.zip)** | [View JSON](decks/lenormand/deck.json)

### 🎴 Playing Cards (52 cards)
Standard playing card divination from medieval Europe. Each suit and rank carries traditional cartomancy meanings.

**[Download](https://github.com/w8s/obsidian-tarot-decks/releases/latest/download/playing-cards.zip)** | [View JSON](decks/playing-cards/deck.json)

### ☯️ I Ching (64 hexagrams)
Ancient Chinese oracle dating back 3000+ years. Each hexagram represents a unique life situation with guidance from the Wilhelm/Baynes translation.

**[Download](https://github.com/w8s/obsidian-tarot-decks/releases/latest/download/i-ching.zip)** | [View JSON](decks/i-ching/deck.json)

## 🚀 Installation

### Method 1: Download ZIP (Recommended for v1.8.0+)
1. Click download link above
2. In Obsidian: Settings → Tarot Practice → Deck Management → "Add deck"
3. Select the downloaded ZIP file
4. Done! Deck is ready to use

### Method 2: Manual JSON Install (v1.7.0+)
1. Download the `deck.json` file from the deck folder
2. In Obsidian: Settings → Tarot Practice → Deck Management → "Add deck"
3. Select the JSON file
4. Done! Deck is ready to use

## 🤝 Contributing

We welcome community-contributed decks! To submit a deck:

1. Fork this repository
2. Create a new folder in `decks/your-deck-name/`
3. Add your `deck.json` file
4. Add a `README.md` explaining your deck
5. Ensure deck is **public domain** or you hold all rights
6. Submit a pull request

See [CONTRIBUTING.md](CONTRIBUTING.md) for detailed guidelines.

## 📋 Deck Requirements

To be included in this repository, decks must:

- ✅ Be public domain OR created by you with all rights
- ✅ Include complete metadata (author, year, tradition)
- ✅ Follow the JSON schema (see CREATING-DECKS.md)
- ✅ Include a README explaining the deck's history/usage
- ✅ Pass validation (no duplicate indices, correct card count)
